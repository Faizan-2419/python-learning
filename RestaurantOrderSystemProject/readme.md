# Restaurant Order Management System
A simple command-line restaurant ordering system built using Python and object-oriented programming.
The program allows users to view a menu, place orders, enter quantities, and generate a final bill.

## Features
* Display restaurant menu
* Select items from the menu
* Enter quantity for each item
* Calculate and display the total bill
* Simple and easy command-line interaction

## Concepts Used
* Object-Oriented Programming (OOP)
* Classes and objects
* Dictionaries for menu and orders
* Loops and conditional statements
* User input handling

## How to Run
1. Make sure Python 3 is installed on your system.
2. Navigate to the project folder.
3. Run the program using the following command:

```id="runrestaurant"
python main.py
```

## Project Purpose
This project was created to practice Python programming and understand how object-oriented programming can be used to build a simple real-world application.
