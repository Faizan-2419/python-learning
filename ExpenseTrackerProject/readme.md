# Expense Tracker
A simple command-line Expense Tracker built with Python.
The program allows users to record daily expenses and calculate total spending. It is designed as a beginner project to practice basic Python programming concepts.

## Features
* Add new expenses
* View all recorded expenses
* Calculate total spending
* Simple command-line interaction

## Project Structure
The project contains a Python script that handles user input, stores expenses, and calculates the total amount spent.

## Concepts Used
* Variables and data types
* Conditional statements
* Loops
* Lists and dictionaries
* User input handling

## How to Run
1. Make sure Python 3 is installed on your system.
2. Download or clone the repository.
3. Run the program using:

```id="p6ph5p"
python main.py
```

## Purpose
The purpose of this project is to practice Python fundamentals and build a simple application using basic programming logic.
