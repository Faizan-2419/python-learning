# Python Learning

This repository contains Python practice programs and small projects focused on building a strong understanding of basic programming concepts. The projects are simple command-line applications written in Python.

## Projects

### 1. Expense Tracker
A basic program to record and manage personal expenses.

**Features**
* Add new expenses
* View recorded expenses
* Calculate total spending

**Concepts Used**
* Variables
* Conditional statements
* Loops
* Lists and dictionaries
* User input

### 2. Restaurant Order Management System
A command-line restaurant ordering system implemented using object-oriented programming.

**Features**
* Display restaurant menu
* Select food items
* Enter quantity for each item
* Generate the total bill

**Concepts Used**
* Classes and objects
* Dictionaries
* Loops
* Functions

## Technologies
* Python 3
* Command Line Interface (CLI)

## Purpose
This repository is used to practice Python programming and build small projects while improving coding and problem-solving skills.
